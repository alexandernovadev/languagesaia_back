# Listas de palabras comunes

`common-words-<idioma>.json`: palabras por orden de frecuencia real, en su forma de diccionario. Las usa `pnpm seed:dictionary`.

Fuente: [FrequencyWords](https://github.com/hermitdave/FrequencyWords) de Hermit Dave, a partir de OpenSubtitles 2018. Contenido bajo licencia CC-BY-SA 4.0. Las listas de aquí son una adaptación: se agruparon las formas conjugadas y se quitaron nombres y palabras de otros idiomas.
